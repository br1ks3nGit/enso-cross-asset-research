Key findings

  • Two names pass the cross-sectional screen, but neither has multi-event history. ROOT and PLMR retain q<0.10 for available-ONI correlation. Both are young listings with only seven severe months in the sample, all concentrated in one completed episode plus July 2026.
  • The largest raw correlations are concentrated in young listings. ROOT has r=0.400, HAC p=0.000, q=0.007; PLMR has r=0.252, HAC p=0.002, q=0.058. Each overlaps only one completed severe episode, so these are fragile ranks rather than stable signals.
  • The catastrophe/property basket did not sell off in severe months. It averaged 1.45% in severe months versus 0.60% otherwise, a 0.85-point difference with HAC p=0.503. The sign is positive but statistically inconclusive.
  • The clearest drawdown candidate is company-specific, not proof of an ENSO channel. UVE lost -35.1% over the 2015-08 to 2016-03 severe window, had a -54.7% maximum drawdown, and lagged SPY by -40.8% on a log-return basis.
  • Extreme moves often reverse inside the same episode. A “Mixed” flag means both a +2σ spike and a −2σ drawdown occurred; this is volatility, not a directional loss signal.

What was tested

The analysis uses monthly log price returns, not price levels. Price levels trend and would create spurious correlation with a persistent climate index. A severe month is defined here as ONI ≥ +1.5°C. The episodes in the supplied ONI file are 2009-12–2010-01 (peak 1.5°C), 2015-08–2016-03 (peak 2.6°C), 2023-09–2024-02 (peak 2.0°C), 2026-07–2026-07 (peak 1.8°C partial).

Two alignments are shown. Contemporaneous ONI matches the revised ONI value to the same month's return and is descriptive only. Available ONI shifts ONI by three months, a conservative publication-timing convention for a centered three-month index. It prevents a trading interpretation from receiving the current revised value prematurely; it is still not a true NOAA vintage archive.

Interpretation

  • Insurance premiums are not losses. Premiums are revenue. Catastrophe claims and loss-adjustment expenses reduce underwriting profit; later premium repricing can improve future margins.
  • ONI is a broad climate-state proxy. It does not identify the peril, landfall, insured geography, policy limits, reinsurance attachment, or claims booked by a specific company.
  • Stock returns mix many channels. Catastrophe claims, reserve revisions, reinsurance recoveries, premium pricing, investment income, interest rates and market beta can offset one another.
  • Statistical significance is not economic causality. A p-value is the probability of data at least this extreme under a specified zero-effect model. It is not the probability that the hypothesis is true. BH q-values control the expected false-discovery share among selected findings.
  • The event count is small. The threshold produces three completed severe episodes after broad daily stock coverage begins, plus a one-month partial 2026 episode. Monthly sample size therefore exaggerates apparent precision if clustering is ignored.
  • Survivorship bias is material. The supplied list contains securities observable in 2026. Failed, acquired or delisted insurers are absent, so average historical resilience can be overstated.

Metric definitions

Monthly log return = ln(P_t / P_(t−1)), using the last split-adjusted daily close in each adjacent calendar month. Dividends are excluded.

Pearson r = cov(X,Y) / (sd(X)·sd(Y)). Here X is ONI and Y is monthly stock return. Values range from −1 to +1.

HAC p is the two-sided p-value for the ONI slope in return_t = α + β·ONI_available,t + ε_t, with Newey–West standard errors and six monthly lags.

Severe − other = mean(return | ONI≥1.5) − mean(return | ONI<1.5). Event HAC p tests the severe-month indicator using the same autocorrelation correction.

Market-relative log return = ln(P_1/P_0) − ln(SPY_1/SPY_0). This is not a regression alpha.

Maximum drawdown = min_t(P_t / max_(s≤t) P_s − 1) within each severe episode, anchored to the last close before onset.

20-day z = (20-day log return − full-history mean) / full-history standard deviation.
